# Triple Espresso

## Descripción del proyecto

**Triple Espresso** es una página web para una cafetería de especialidad ubicada en Triple Peaks. Su objetivo es presentar el espacio como una zona de estudio, comunicar los horarios y la ubicación de la cafetería, y ofrecer accesos a las secciones de reserva y contacto.

La página cuenta con una cabecera informativa, una barra de navegación con enlaces internos, una imagen principal de la cafetería y una identidad visual construida con imágenes y tipografías personalizadas.

## Tecnologías utilizadas

- HTML5 para la estructura y el contenido semántico de la página.
- CSS3 para los estilos, la distribución de los elementos y el diseño visual.
- Metodología BEM para organizar las clases de CSS.
- Normalize.css para mantener una visualización consistente entre navegadores.
- Fuentes, imágenes y gráficos SVG almacenados localmente como recursos del proyecto.
